# `tinybfv` [![CI](https://github.com/0xWOLAND/tinybfv/actions/workflows/ci.yml/badge.svg)](https://github.com/0xWOLAND/tinybfv/actions/workflows/ci.yml)

Una implementación ligera del esquema de cifrado homomórfico BFV (Brakerski/Fan-Vercauteren) utilizando TinyGrad.

## Características

- Suma y multiplicación homomórfica básica
- Generación de claves, cifrado y descifrado
